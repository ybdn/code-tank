# Sécurité

## Signaler une faille

Écris à **support@ybdn.io**, avec l'objet « Code Tank — faille ». Décris ce que tu as vu et comment le reproduire.
N'ouvre pas de ticket public pour une faille et ne teste rien sur les données d'autres personnes.

Ce dépôt ne contient aucun secret : si tu en trouves un, signale-le de la même façon.

## Périmètre

Le code de ce dépôt, le site `code-tank.ybdn.io` une fois en ligne. Les consignes des jurés et les règles de détection
de manipulation sont dans un dépôt privé et ne sont pas distribuées.
